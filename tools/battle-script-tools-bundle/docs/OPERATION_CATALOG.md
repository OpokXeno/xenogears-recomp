## Comparison Selectors

`flow.jump_unless` (`02`) stores the comparison in the low nibble of its
mask byte. Bits `0x20` and `0x10` are not read and appear as
`reserved_flags` when set.

| Selector | XGS condition | Test |
|---:|---|---|
| `0` | `a == b` | left == right |
| `1` | `a != b` | left != right |
| `2` | `a > b` | (s16)left > (s16)right |
| `3` | `a < b` | (s16)left < (s16)right |
| `4` | `a >= b` | (s16)left >= (s16)right |
| `5` | `a <= b` | (s16)left <= (s16)right |
| `6` | `a & b` | (left & right) != 0 |
| `7` | `compare(a, b, 7)` | left != right (second encoding) |
| `8` | `a \|\| b` | left != 0 \|\| right != 0 |
| `9` | `mask_contains(a, b)` | Battle entity right is in target mask left |
| `A` | `mask_lacks(a, b)` | Battle entity right is absent from target mask left |
| `B` | `compare(a, b, 11)` | false |
| `C` | `compare(a, b, 12)` | false |
| `D` | `compare(a, b, 13)` | false |
| `E` | `compare(a, b, 14)` | false |
| `F` | `compare(a, b, 15)` | false |
